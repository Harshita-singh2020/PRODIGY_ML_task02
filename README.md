# PRODIGY_ML_task02

## 🛍️ Customer Segmentation Using K-Means Clustering

This project was completed as part of my **Machine Learning Internship at Prodigy Infotech**.

The objective of this project is to apply **K-Means Clustering** to segment customers of a retail store based on their purchasing behavior and demographic characteristics.

The clustering technique helps identify different groups of customers with similar characteristics, which can be useful for understanding customer behavior and developing targeted marketing strategies.

## 📌 Project Objective

The main objective is to:

- Analyze customer data
- Explore relationships between customer attributes
- Apply K-Means Clustering
- Identify meaningful customer segments
- Visualize the resulting clusters
- Understand the characteristics of different customer groups

## 📊 Dataset

The project uses the **Mall Customer Segmentation Dataset**.

The dataset contains information about customers such as:

- Customer ID
- Gender
- Age
- Annual Income
- Spending Score

## 🛠️ Technologies Used

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## 🤖 Machine Learning Algorithm

### K-Means Clustering

K-Means is an **unsupervised machine learning algorithm** used to divide data into a predefined number of clusters.

Customers within the same cluster have similar characteristics, while customers belonging to different clusters have relatively different characteristics.
